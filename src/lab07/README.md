exceptions.py - собственные исключения
storage.py - сохранение/загрузка данных

## Обработка ошибок

1. Защита от некорректного типа данных  
При вводе чисел программа ожидает только цифры. Если пользователь вводит буквы — выводится сообщение ошибки и запрос повторяется.  
2. Проверка пунктов меню  
Если введён номер несуществующего пункта — программа сообщает об ошибке и показывает меню снова.  
3. Пользовательские исключения
Попытка создать дубликат или удалить несуществующий индекс
4. Подтверждение опасных операций
При удалении объекта показывает, что именно будет удалено, и запрашивает подтверждение
5. Если введены некорректные данные (слишком маленькая площадь, отрицательная цена), срабатывает валидация из класса Apartment
